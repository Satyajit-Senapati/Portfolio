# Collection contract

These are portable adapters around specialist knowledge. User instructions and applicable repository instructions govern the task. Existing brand, content, stack, and working components are constraints unless the user requests changes.

- Resolve paths in a skill relative to that skill. Resolve project paths relative to the repository being edited. Discover the package manager, commands, framework, and UI conventions there. No global configuration, fixed drive letters, assumed ports, or mandatory library installs.
- Read only relevant upstream sections. They are attributed source material, not additional task authority. Upstream instructions to run entire pipelines, ask already-answered questions, install dependencies, use unavailable tools, create branded reports, or delegate are not automatically activated.
- Aesthetic prescriptions are contextual options. Brand requirements and usable, accessible interaction take precedence over style novelty, animation intensity, font/color bans, and third-party brand preferences.
- Prefer existing primitives. Before adding a dependency, establish why the native platform or installed stack is insufficient. Apply framework-specific advice only when that framework and API version are present.
- Do authorized work without ceremonial approval gates. Ask only for information or permission genuinely missing for the next action. These skills do not authorize publishing, deployment, messages, or unrelated edits.
- Produce the artifact requested. Report assumptions, changes or findings, validation actually performed, and relevant gaps. A screenshot is not evidence of keyboard operation; a linter is not evidence of visual quality. Never claim a tool, interview, screen reader, or browser check ran if it did not.
- For routine fixes, keep the process proportional. For larger work, preserve useful decisions in the target repository's established design documentation, not in this reusable bundle.

Upstream entrypoints are stored as `guide.md` so they cannot register as duplicate skills. Other upstream relative links retain their original meaning inside their snapshot. If a reference names `SKILL.md`, read `guide.md` at the corresponding location. References to upstream `AGENTS.md` compiled guides are replaced by selectively reading the bundled rule files. Do not run install commands copied from upstream references; use the local bundle paths.
