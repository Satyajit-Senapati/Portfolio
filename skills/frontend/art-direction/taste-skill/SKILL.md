# Art direction with TasteSkill

Apply [the shared contract](../../shared/contract.md). Use the pinned [TasteSkill guide](references/upstream/guide.md), reading its brief inference and the sections matching this page type. Source and license: [sources](../../SOURCES.md).

Before editing, identify the intended audience, primary action, existing brand, page density, and what must be retained. In a redesign, inspect the current page and separate hierarchy problems from subjective taste. State a concise visual direction grounded in the actual subject and content.

Choose a small set of deliberate decisions: type hierarchy, spacing rhythm, image treatment, palette roles, and one memorable compositional element. Treat upstream numerical dials and presets as optional vocabulary; do not automatically raise motion or layout variance. Keep established design systems and font choices unless replacing them is part of the brief.

Work from large-scale hierarchy to component detail. Check the first viewport, scanning order, headline wrapping, content measure, alignment, image quality, and primary action before adding decoration. Judge quiet and expressive directions by how well they serve this audience. Do not fabricate product facts, endorsements, or evidence to fill a composition.

Deliver working changes when implementation was requested. Explain the design decisions briefly and inspect the result at a narrow and wide viewport when browser tooling is available. Use the separate visual-QA skill for a broader regression pass.
