# Frontend work

For UI creation, redesign, UX planning, responsive changes, motion, or UI reviews, read `skills/frontend/frontend-selector/SKILL.md` and load only the specialists appropriate to the task. Explicit specialist requests can go directly to their skill. Do not load the entire collection for every task.

Project context: read `docs/architecture.md` for this portfolio's design system, content conventions, responsive behavior, and motion constraints. Inspect the current source before changing those conventions. The project uses React, TypeScript, Vite, and native CSS; `package.json` defines its validation commands. The portable skills should remain free of project-specific settings.
